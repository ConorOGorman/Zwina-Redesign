# Brand Token Surfaces

## Approved for Brand Updates
The following CSS variables in `/styles/tokens.css` may be updated to match brand guidelines:

### Colors
- `--primary`: Main brand color (Buttons, Links, Highlights)
- `--secondary`: Secondary background color (Section backgrounds)
- `--accent`: Accent color (Success states, specific highlights)
- `--background`: Page background
- `--foreground`: Body text color

### Typography
- `--font-sans`: Primary font family
- `--font-serif`: Heading font family (if applicable)

## RESTRICTED (DO NOT CHANGE)
- `--spacing-*`: Spacing scale defines the layout rhythm.
- `--motion-*`: Animation timing defines the interaction feel.
- Breakpoints in Tailwind config.

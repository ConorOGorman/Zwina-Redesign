# Injection Playbook

## Homepage (`/`)
1. **HeroSection**: Update headline, subheadline, CTA labels.
2. **IntroValuesSection**: Update "Who We Are" text and value props.
3. **ProgramHighlightSection**: Update Zwina Challenge details.
4. **ProjectsGridSection**: Update project cards (Morocco, Bangladesh).
5. **CampaignSection**: Update Christmas campaign text/stats.
6. **VisionStatsSection**: Update vision stats.
7. **ProductCarouselSection**: Update featured products list.
8. **ContentSplitSection**: Update "Handcrafted" text.
9. **CtaSection**: Update contact text and links.
10. **CrowdfundingSection**: Update movement text.
11. **PartnersLogosSection**: Update partner names/logos.
12. **NewsletterSection**: Update subscription text.

## Generic Pages
For `/about`, `/projects`, `/shop`, etc.:
1. **PageHeaderSection**: Update `title` and `description` props.
2. **ContentSection**: Update `content` prop or children text.
